# Cap07 - at02_validacaoTratamentoErros

Atividade que implementa validação de entrada e tratamento centralizado de erros em uma API Express.

## Conteúdo
- Validação de dados de requisição
- Middleware global de tratamento de erros
- Respostas consistentes para falhas

## Como executar
```bash
cd Cap07/at02_validacaoTratamentoErros
npm install
npm test
```

## Observações
A atividade melhora a robustez da API por meio de controles de fluxo de erro e mensagens padronizadas.
