# Cap07 - at01_segurancaAplicacao

Atividade que aplica segurança em APIs Express usando Helmet, rate limiting e configurações de CORS.

## Conteúdo
- Proteção de headers HTTP
- Limitação de requisições por IP
- Configuração de CORS para front-end autorizado

## Como executar
```bash
cd Cap07/at01_segurancaAplicacao
npm install
npm test
```

## Observações
A atividade foca em endurecer a aplicação contra ataques comuns e reforçar boas práticas de segurança.
