# Cap07 - at04_testesAvancados

Atividade dedicada a testes avançados de API, com mocks e validação de fluxos críticos.

## Conteúdo
- Testes unitários e de integração com `vitest`
- Uso de `supertest` para rotas Express
- Simulação de serviços externos e autenticação

## Como executar
```bash
cd Cap07/at04_testesAvancados
npm install
npm test
```

## Observações
A atividade reforça a importância de testes automatizados no ciclo de desenvolvimento.
