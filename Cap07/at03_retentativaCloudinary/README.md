# Cap07 - at03_retentativaCloudinary

Atividade que adiciona retry e limpeza de arquivo em uploads para Cloudinary.

## Conteúdo
- Upload de imagens para Cloudinary
- Lógica de retry para falhas transitórias
- Cleanup em caso de falha após upload parcial

## Como executar
```bash
cd Cap07/at03_retentativaCloudinary
npm install
npm test
```

## Observações
A atividade demonstra resiliência em integrações com serviços externos.
