# Cap07 - at05_documentacaoSwagger

Atividade que adiciona documentação Swagger à API, com UI interativa e especificações OpenAPI.

## Conteúdo
- Configuração de Swagger UI
- Especificação OpenAPI em YAML
- Rota de documentação integrada à aplicação

## Como executar
```bash
cd Cap07/at05_documentacaoSwagger
npm install
npm test
```

## Observações
A documentação facilita o consumo da API por clientes e integrações.
