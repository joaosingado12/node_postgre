# Cap04 - at05_JLerGravarJSON

Esta atividade demonstra leitura e gravação de arquivos JSON em uma aplicação Express.

## Conteúdo
- Rotas para gravar e ler arquivos JSON
- Manipulação de dados enviados pelo cliente

## Como executar
```bash
cd Cap04/at05_JLerGravarJSON
npm install
node index.js
```

## Observações
Verifique as permissões de escrita na pasta antes de executar a aplicação.
