# Cap04 - at01_ExpressHTTP

Esta atividade introduz o uso do Express para criar um servidor HTTP simples.

## Conteúdo
- Criação de servidor com Express
- Rotas básicas GET e POST
- Estrutura de projeto Express

## Como executar
```bash
cd Cap04/at01_ExpressHTTP
npm install
node server.js
```

## Observações
O foco é entender o fluxo de rotas e a arquitetura básica de uma aplicação Express.
