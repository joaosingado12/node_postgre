# Cap04 - at03_QueryParams

Esta atividade trabalha com query parameters em rotas Express.

## Conteúdo
- Uso de `req.query`
- Filtragem e paginação por query strings
- Validação simples de parâmetros de consulta

## Como executar
```bash
cd Cap04/at03_QueryParams
npm install
node index.js
```

## Observações
Query params são essenciais para APIs que precisam buscar ou filtrar dados.
