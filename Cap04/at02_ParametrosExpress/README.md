# Cap04 - at02_ParametrosExpress

Esta atividade mostra como capturar parâmetros de rota no Express.

## Conteúdo
- Rotas com parâmetros dinâmicos
- Leitura de valores enviados na URL
- Uso de `req.params`

## Como executar
```bash
cd Cap04/at02_ParametrosExpress
npm install
node server.js
```

## Observações
Útil para construir APIs REST que dependem de identificadores na rota.
