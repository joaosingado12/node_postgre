# Cap06 - at05_resgistrosLogsAPI

Atividade que implementa registros de eventos e logs em uma API.

## Conteúdo
- Registro de requisições e respostas
- Tratamento de erros com log
- Persistência de logs em arquivos ou serviços

## Como executar
```bash
cd Cap06/at05_resgistrosLogsAPI
npm install
npm test
```

## Observações
Os logs ajudam a auditar e diagnosticar falhas em produção.
