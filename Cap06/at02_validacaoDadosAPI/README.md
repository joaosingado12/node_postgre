# Cap06 - at02_validacaoDadosAPI

Atividade que demonstra validação de dados de entrada para APIs.

## Conteúdo
- Validação de requisições
- Tratamento de erros de validação
- Resposta consistente para campos inválidos

## Como executar
```bash
cd Cap06/at02_validacaoDadosAPI
npm install
npm test
```

## Observações
A validação evita entrada indevida e melhora a experiência do cliente da API.
