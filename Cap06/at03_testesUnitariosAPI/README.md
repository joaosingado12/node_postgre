# Cap06 - at03_testesUnitariosAPI

Atividade que demonstra testes unitários em APIs Node.js.

## Conteúdo
- Configuração de `vitest`
- Testes de rotas e controllers
- Uso de mocks para isolar dependências

## Como executar
```bash
cd Cap06/at03_testesUnitariosAPI
npm install
npm test
```

## Observações
Testes unitários são essenciais para garantir regressões e qualidade de código.
