# Cap06 - at06_documentation

Atividade que adiciona documentação de API ao projeto.

- Geração de documentação automatizada

## Como executar
```bash
cd Cap06/at06_documentation
npm install
npm test
```

Documentação facilita uso da API por desenvolvedores e clientes.
