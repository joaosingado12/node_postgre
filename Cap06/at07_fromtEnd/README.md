# Cap06 - at07_fromtEnd

Esta atividade demonstra a integração do back-end com um front-end simples, exibindo dados ou consumindo APIs.

## Conteúdo
- Exemplo de integração entre servidor e front-end
- Possível uso de templates ou front-end estático

## Como executar
```bash
cd Cap06/at07_fromtEnd
npm install
node server.js
```

## Observações
O front-end pode precisar de um servidor local adicional ou ajustes de CORS conforme o caso.
