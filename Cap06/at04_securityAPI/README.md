# Cap06 - at04_securityAPI

Atividade que adiciona camadas de segurança a uma API Express.

## Conteúdo
- Proteção com `helmet`
- Limitação de taxa com `express-rate-limit`
- Configuração de CORS segura

## Como executar
```bash
cd Cap06/at04_securityAPI
npm install
npm test
```

## Observações
A atividade mostra como reduzir superfícies de ataque em APIs.
