# Cap05 - Banco de Dados e CRUD

[⬅ Voltar ao projeto principal](../README.md)

Este capítulo introduz acesso a banco de dados, criação de esquemas SQL e operações CRUD.

## Conteúdo
- `at01-CreateDatabase/`
- `at02-AcessoAoBanco/`
- `at03-CrudCompleto/`
- `at04_CrudAuthMvc/`
- `at05_CrudORMPrisma/`

## Objetivos
- Criar banco de dados e tabelas
- Conectar-se ao banco com Node.js
- Implementar CRUD completo
- Explorar ORM com Prisma

## Configuração
- Entre na pasta da atividade desejada.
- Execute `npm install` para instalar as dependências.
- Copie o conteúdo do arquivo `envExemple` para um arquivo `.env` e ajuste os valores conforme o banco local.

## Comandos
```bash
cd Cap05/at02-AcessoAoBanco
npm install
node index.js
```

## Variáveis de ambiente
- `PORT` - porta do servidor.
- `DB_HOST` - host do banco.
- `DB_USER` - usuário do banco.
- `DB_PASSWORD` - senha do banco.
- `DB_NAME` - nome do banco.

## Observações
Algumas atividades usam MySQL e PostgreSQL. Ajuste as variáveis conforme o seu ambiente.
