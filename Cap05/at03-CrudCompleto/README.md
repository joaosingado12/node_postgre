# Cap05 - at03-CrudCompleto

Atividade de implementação de um CRUD completo em Node.js com banco de dados.

## Conteúdo
- Criação, leitura, atualização e exclusão de registros
- Uso de rotas REST
- Conexão com banco e manipulação de dados

## Como executar
```bash
cd Cap05/at03-CrudCompleto
npm install
node index.js
```

## Observações
A atividade mostra um fluxo completo de API com persistência em banco.
