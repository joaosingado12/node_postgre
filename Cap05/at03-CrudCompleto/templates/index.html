API Amigo do Pet

Documentação Completa do Sistema CRUD Dinâmico

Gestão de Usuários

Método Endpoint Descrição
POST/usuariosCadastra um novo usuário no banco.
GET/usuariosLista todos os registros da tabela usuarios.
GET/usuarios/1Busca um usuário específico pela Chave Primária.
PUT/usuarios/1Atualiza dados dinamicamente usando o ID.
DELETE/usuarios/1Remove o registro permanentemente.

Exemplo JSON (POST/PUT)

{
  "nome": "Leonardo Fernandes",
  "cpf": "12345678901",
  "telefone": "17999999999",
  "whatsapp": "17988888888",
  "email": "leo@email.com",
  "senha": "123"
}

Regras de Negócio

  • O CPF deve ter exatamente 11 dígitos.
  • Email e CPF são campos únicos.
  • Excluir um usuário remove em cascata seus pets.

Gestão de Animais

Método Endpoint Descrição
POST/petsVincula um novo pet a um usuário existente.
GET/petsRetorna a lista completa de animais.
GET/pets/10Detalhes do animal pelo ID.
PUT/pets/10Atualiza status, peso ou observações.
DELETE/pets/10Exclui o animal do sistema.

Exemplo JSON (POST)

{
  "id_cli": 1,
  "nome": "Rex",
  "sexo": "M",
  "especie": "Cachorro",
  "raca": "Labrador",
  "peso": 25.5,
  "tamanho": "Grande",
  "idade": 3,
  "doenca": "Nenhuma",
  "obs": "Dócil e vacinado"
}

Dica de Integração

O campo id_cli é a Chave Estrangeira que conecta o animal ao seu dono na tabela usuarios.

Gestão de Doações

Método Endpoint Descrição
POST/doacoesRegistra uma nova intenção de adoção.
GET/doacoesConsulta o histórico de todas as doações.
PUT/doacoes/5Finaliza a doação ou altera o status.
DELETE/doacoes/5Cancela o registro de doação.

Exemplo JSON (Fase Final)

{
  "id_pet": 10,
  "id_cli_interesse": 2,
  "data_interesse": "2026-05-01",
  "data_doacao": "2026-05-08",
  "status": "Concluído"
}

Estados de Doação

  • Interessado: Alguém quer adotar.
  • Em Análise: Entrevista em curso.
  • Concluído: O pet tem um novo lar!
