# Cap05 - at04_CrudAuthMvc

Atividade que demonstra um CRUD com autenticação e arquitetura MVC.

## Conteúdo
- Estrutura MVC com `models`, `views` e `controllers`
- Autenticação de usuários
- Rotas para manipulação de dados

## Como executar
```bash
cd Cap05/at04_CrudAuthMvc
npm install
node server.js
```

## Observações
A atividade mostra uma arquitetura mais próxima de aplicações reais.
