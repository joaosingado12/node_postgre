# Cap05 - at01-CreateDatabase

Atividade de criação do banco de dados com scripts SQL para as tabelas iniciais do projeto.

## Conteúdo
- Scripts SQL para criação de tabelas
- Estrutura de dados para usuários, pets e doações

## Como usar
Abra o arquivo `at01-CreateDatabase/amigo_do_pet_PostgreSQL.sql` ou `amigo_do_pet_MySQL.sql` e execute no seu banco de dados.

## Observações
A atividade não depende de Node.js para execução, apenas do acesso ao banco de dados.
