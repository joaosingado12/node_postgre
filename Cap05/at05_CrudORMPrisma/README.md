# Cap05 - at05_CrudORMPrisma

Atividade que implementa CRUD usando Prisma ORM.

## Conteúdo
- Configuração do Prisma
- Modelo de dados com `schema.prisma`
- Operações de criação, leitura, atualização e exclusão

## Como executar
```bash
cd Cap05/at05_CrudORMPrisma
npm install
npm run dev
```

## Observações
Certifique-se de rodar `prisma generate` se necessário antes de iniciar o projeto.
