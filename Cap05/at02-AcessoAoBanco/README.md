# Cap05 - at02-AcessoAoBanco

Atividade que demonstra o acesso a banco de dados a partir de Node.js.

## Conteúdo
- Conexão com o banco usando `pg` ou `mysql2`
- Consulta e inserção de dados
- Uso de variáveis de ambiente para credenciais

## Como executar
```bash
cd Cap05/at02-AcessoAoBanco
npm install
node index.js
```

## Observações
Verifique `envExemple` e ajuste as credenciais do banco antes de executar.
