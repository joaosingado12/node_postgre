# Cap02 - at05_ModulosProprios

Esta atividade demonstra a criação e o uso de módulos próprios em Node.js.

## Conteúdo
- Importação de módulos locais
- Exportação de funções e variáveis
- Estrutura de pastas para reutilização de código

## Como executar
```bash
node Cap02/at05_ModulosProprios/index.js
```

## Observações
A atividade reforça a modularização de código em aplicações Node.js.
