# Cap03 - HTTP, URLs e Renderização

[⬅ Voltar ao projeto principal](../README.md)

Neste capítulo, são criadas aplicações HTTP simples e páginas HTML renderizadas a partir de Node.js.

## Conteúdo
- `at01_olaMundo.js`
- `at02_parametrosURL.js`
- `at03_RenderHTML/`

## Objetivos
- Criar um servidor HTTP básico
- Trabalhar com parâmetros de URL
- Renderizar arquivos HTML

## Configuração
- Pré-requisito: Node.js instalado.
- Não há variáveis de ambiente obrigatórias para este capítulo.

## Comandos
```bash
node Cap03/at01_olaMundo.js
```

## Variáveis de ambiente
Nenhuma variável de ambiente é necessária para os exemplos deste capítulo.

## Observações
O capítulo mostra a transição de scripts simples para serviços web com renderização de views.
